# Release Information
Below is a list of all the releases for SyncFlow. Each release includes a summary of the changes, new features, and bug fixes. 

## Version 0.1.0
This was the initial release of SyncFlow featuring a single tenant architecture with a single project and session. The release included the following features:

- **Livekit Integration**: SyncFlow was integrated with Livekit to provide real-time audio and video streaming capabilities.
- **Session Management**: Users could create and manage sessions, including starting and stopping sessions, and managing participants.

## Version 0.2.0
This release introduced a multi-tenant architecture, allowing multiple projects and sessions to be managed within SyncFlow. The release included the following features:

- **Multi-Tenant Architecture**: SyncFlow was updated to support multiple projects and sessions, allowing for better organization and management of resources.
- **Ecosystem Integration**: SyncFlow was integrated with other tools and services to provide a more comprehensive solution for multimodal learning analytics.


Detailed release notes for each version can be found in the [release notes](https://github.com/oele-isis-vanderbilt/SyncFlow/releases).
